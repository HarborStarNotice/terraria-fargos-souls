# Fargo's Souls Mod

### The ultimate Terraria challenge and content mod

Fargo's Souls Mod adds a deep challenge mode system, powerful soul accessories crafted from boss drops, and an Eternity Mode difficulty that transforms every boss into a dramatically harder encounter.

<br>

---

## Features

| | |
|:---|:---|
| **Eternity Mode** | Completely reworked bosses with new attacks, phases, and behaviors |
| **Soul Accessories** | Combine boss drops into powerful meta-accessories with stacking effects |
| **Enchantments** | Unique weapon enchantments that add special effects to any tool |
| **Cross-Mod Compat** | Deep compatibility with Calamity, Thorium, and other major mods |
